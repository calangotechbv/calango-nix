# calango-nix Hyprland Configuration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace spec 1's three-keybind placeholder with calango-desktop's real
`hyprland.lua`, its per-host outputs and its idle behaviour, with runtime-written
state in `~/.local/state/hypr` where Home Manager cannot turn it read-only.

**Architecture:** `hypr/` is forked into calango-nix and its loading logic
rewritten from `require()` to `dofile()` with build-time-substituted absolute
paths. A derivation puts the tree in the store with the host baked in. The
compositor gets its `PATH` from the `hyprland-nixgl` wrapper; hypridle gets
absolute store paths in its generated config.

**Tech Stack:** Hyprland 0.55.4 (Lua config), nixpkgs `nixos-26.05`,
home-manager `release-26.05`, nixGL, hypridle 0.1.7, hyprlock 0.9.5.

**Spec:** `docs/superpowers/specs/2026-08-14-hyprland-design.md`

## Global Constraints

- **State lives in `~/.local/state/hypr`.** Home Manager manages nothing there
  except a `.keep`.
- **Every `dofile` stays wrapped in `pcall`.** `dofile` raises on a missing
  file, and two of the four state files legitimately do not exist yet. A
  machine that has never opened the monitor panel must still start.
- **The compositor's `PATH` is explicit,** set in the `hyprland-nixgl` wrapper.
  Nothing else on this machine puts the Nix profile on it.
- **hypridle's config names absolute store paths,** never bare command names.
- **`~/Projects/calango-desktop` is never modified and is never a flake input.**
- **`hypridle.conf`, the four state files and `systemd/` are not forked.**
- **Nix commands need `sg nix-users -c '...'`;** the flake only sees
  git-tracked files, so `git add` before every build.

### Task 3: The derivation, and a host-aware flake

**Files:**
- Create: `home/hyprland.nix`
- Modify: `flake.nix` — `mkHome` gains a host parameter

**Interfaces:**
- Consumes: Task 2's tokenised tree.
- Produces: `config.calango.hyprConfig`, a store path whose `hyprland.lua` has
  every token substituted, for Tasks 6 and 7.

- [ ] **Step 1: Write the module**

Create `home/hyprland.nix`:

```nix
{ config, lib, pkgs, ... }:

let
  # The state directories these paths point at. Declared here rather than
  # inline so the module and the substitutions cannot drift apart.
  hyprState = "${config.home.homeDirectory}/.local/state/hypr";
  quickshellState = "${config.home.homeDirectory}/.local/state/quickshell";

  hyprConfig = pkgs.runCommand "hypr-config" { } ''
    cp -r ${./../hypr} "$out"
    chmod -R u+w "$out"

    substituteInPlace "$out/hyprland.lua" \
      --replace-fail '@hyprSource@'      "$out" \
      --replace-fail '@host@'            '${config.calango.host}' \
      --replace-fail '@quickshellState@' '${quickshellState}'
    # @hyprState@ appears three times, so --replace-fail's single-occurrence
    # guarantee does not apply; --replace is correct here and the count is
    # asserted immediately afterwards instead.
    substituteInPlace "$out/hyprland.lua" \
      --replace '@hyprState@' '${hyprState}'

    if grep -q '@[a-zA-Z]*@' "$out/hyprland.lua"; then
      echo "unsubstituted token left in hyprland.lua:" >&2
      grep -n '@[a-zA-Z]*@' "$out/hyprland.lua" >&2
      exit 1
    fi
  '';
in
{
  options.calango = {
    host = lib.mkOption {
      type = lib.types.str;
      description = "Which hosts/<name>.lua this configuration bakes in.";
    };
    hyprConfig = lib.mkOption {
      type = lib.types.package;
      readOnly = true;
      description = "The Hyprland config tree, in the store.";
    };
  };

  config.calango.hyprConfig = hyprConfig;
}
```

The trailing `grep` is the safety net for `@hyprState@`: `--replace` does not
fail on a missing match the way `--replace-fail` does, so the build asserts
that no token survives rather than trusting the substitution.

### Task 6: hypridle, with paths that name what they mean

**Files:**
- Modify: `home/hyprland.nix`
- Modify: `home/default.nix` — remove spec 1's placeholder `services.hypridle`

**Interfaces:**
- Consumes: Task 3's module.
- Produces: a `hypridle.service` whose commands are absolute store paths, and
  a PATH-wrapped `idle-sleep.sh`.

**This task fixes a live defect.** Spec 1 configured
`lock_cmd = pidof hyprlock || hyprlock` as bare names, and `hypridle.service`
has `Environment=` empty. On the default unit `PATH` those resolve to
`/usr/bin/hyprlock` — Debian's 0.55.2 from `trixie-backports`, not the Nix
build. It works today only because that package is installed; spec 6 removes
it and the screen stops locking silently.

- [ ] **Step 1: Show the defect before fixing it**

```bash
systemctl --user show hypridle.service -p Environment
systemd-run --user --wait --pipe --quiet /bin/sh -c 'command -v hyprlock'
```

Expected: `Environment=` empty, then `/usr/bin/hyprlock`. That second line is
the defect: apt's binary, in a session that is supposed to be Nix's.

- [ ] **Step 2: Move hypridle into `home/hyprland.nix`**

Delete the `services.hypridle` block from `home/default.nix` — spec 1's
placeholder, with its single 900-second listener — and add the real
configuration to `home/hyprland.nix`, translated from
`calango-desktop/hypr/hypridle.conf`:

```nix
  # Absolute store paths, never bare names. hypridle.service has no explicit
  # PATH, so a bare `hyprlock` resolves against the default unit PATH and
  # finds Debian's /usr/bin/hyprlock -- which disappears when spec 6 removes
  # trixie-backports, taking the lock screen with it and saying nothing.
  config.services.hypridle = {
    enable = true;
    settings = {
      general = {
        lock_cmd = "${pkgs.procps}/bin/pidof hyprlock || ${pkgs.hyprlock}/bin/hyprlock";
        before_sleep_cmd = "${pkgs.systemd}/bin/loginctl lock-session";
        after_sleep_cmd = "${pkgs.hyprland}/bin/hyprctl dispatch dpms on";
      };
      listener = [
        {
          timeout = 300;
          on-timeout = "${pkgs.systemd}/bin/loginctl lock-session";
        }
        {
          timeout = 330;
          on-timeout = "${pkgs.hyprland}/bin/hyprctl dispatch dpms off";
          on-resume = "${pkgs.hyprland}/bin/hyprctl dispatch dpms on";
        }
        {
          timeout = 900;
          on-timeout = "${idleSleep}/bin/idle-sleep";
          on-resume = "${idleSleep}/bin/idle-sleep --cancel";
        }
      ];
    };
  };
```

- [ ] **Step 3: Wrap `idle-sleep.sh` with a PATH**

Add to the `let` block in `home/hyprland.nix`:

```nix

  # loginctl, busctl, grep, awk and pkill. hypridle.service has no explicit
  # PATH, so each of those is a silent failure waiting to happen -- the
  # machine simply never suspends, with nothing in the journal to say why.
  idleSleepPath = lib.makeBinPath (with pkgs; [
    coreutils systemd gnugrep gawk procps
  ]);

  idleSleep = pkgs.writeShellScriptBin "idle-sleep" ''
    export PATH=${idleSleepPath}''${PATH:+:$PATH}
    exec ${config.calango.hyprConfig}/idle-sleep.sh "$@"
  '';
```

## Where this plan stops

The compositor runs calango-desktop's real configuration from the store, with
state in `~/.local/state/hypr` and a lock screen that is Nix's. The terminals,
`lf`, the GTK theming and the `~/.local/bin` shims are still unported, so any

## Open items this plan does not close

- **`idle-sleep.sh` could be simpler under Nix.** Its header explains it
  decides laptop-versus-desktop at runtime because hypridle could not reach a
  per-host mechanism. Home Manager generates that config per host now. The
  battery check must stay runtime; the laptop check need not. Not done here.
- **Whether Hyprland prefers `.lua` over `.conf`** when both exist. This plan
  deletes the `.conf` and passes `--config` explicitly rather than depending
  on the answer.
- **`apply-gtk-theme` is comment-only** in `hyprland.lua`. If Task 8's runtime
  gate proves otherwise, it will not resolve until spec 4.
